# MuseHub 第五阶段交互巡检报告

## 巡检页面

- `#/home`：搜索、来源切换、热门词、推荐歌单、趋势歌曲、查看全部。
- `#/search`：来源切换、分类标签、排序按钮、播放、收藏、相关热搜、搜索历史、迷你播放器。
- `#/favorites`：收藏、稍后听、最近播放、本地歌单、新建歌单、筛选、删除、视图切换、本地导入入口。
- `#/playlists` 与 `#/playlist?id=...`：新增基础歌单页和歌单详情页。
- `#/player`：返回、分享、更多、收藏、播放控制、进度、随机、循环、歌词、播放列表。
- `#/lyrics`：返回播放器、退出全屏、歌词设置、播放控制、进度。
- `#/settings`：默认搜索来源、自动换源、主题、动画、播放器样式、歌词设置、清理缓存、关于信息。

## 已完整实现

- 顶部导航全部可跳转，`歌单` 已接入 `#/playlists`。
- 首页搜索、Enter 搜索、来源切换、热门词跳转、推荐歌单跳转。
- 搜索页真实搜索、来源切换、收藏、搜索历史、清空历史、播放按钮状态同步。
- 新建歌单弹窗、歌单列表、歌单详情、空歌单状态。
- 收藏页本地收藏、稍后听、最近播放统计、收藏筛选、删除确认、网格/列表切换。
- 播放器页与歌词页的返回、播放/暂停、上一首、下一首、进度、随机/循环 UI 状态。
- 分享当前歌曲信息到剪贴板，剪贴板不可用时给出 Toast。
- 设置项保存到 `musehub:settings`，清理缓存不会删除收藏和歌单。

## Toast 或半实现入口

- 搜索分类里的歌手、专辑、歌单、歌词、MV：保留 UI，提示后续版本开放。
- 综合排序：当前按接口返回顺序展示，点击提示后续补更多排序。
- 本地音乐库、导入音乐：提示本地导入将在后续版本开放。
- 添加歌曲到歌单、歌词颜色预设：当前 Toast 提示。
- 空播放器上的收藏/播放控制：提示先播放一首歌。

## 后续版本建议

- 给歌单增加“添加当前歌曲”“拖拽排序”“删除歌单”。
- 收藏页增加更多排序维度与持久化视图偏好。
- 搜索分类接入歌手、专辑、歌单、MV 等真实接口。
