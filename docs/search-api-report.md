# 无界音乐 MuseHub 搜索 API 改造报告

## 改造文件

- `js/api.js`：统一 V2 API 域名、GET 请求、超时和错误处理。
- `js/normalize.js`：新增/完善 QQ 音乐、网易云音乐歌曲标准化逻辑。
- `js/search-service.js`：封装搜索业务，支持 `all` 并行聚合。
- `js/ui.js`：首页搜索跳转、搜索页真实请求、状态渲染、来源切换、分类提示、收藏兼容。
- `js/storage.js`：搜索历史改为真实本地写入，不再默认注入 mock 历史。
- `css/components.css`：补充真实封面和未实现分类样式。
- `css/pages.css`：补充搜索 loading、empty、error、partial warning 样式。
- `index.html`：更新静态资源版本号。

## 完成功能

- 首页搜索框支持点击搜索和 Enter 搜索。
- 首页来源按钮支持全部、QQ 音乐、网易云音乐切换，并携带到搜索页 URL。
- 搜索页读取 `q`、`source`、`page` 参数并自动搜索。
- 搜索页支持全部聚合、QQ 音乐、网易云音乐来源切换。
- 搜索结果使用接口返回的真实歌名、歌手、专辑、时长、封面、来源平台。
- `source=all` 时并行请求两个平台并合并展示。
- 搜索历史使用 `musehub:search-history`，支持去重、最新置顶、最多 8 条、点击复搜、清空。
- 搜索结果收藏按钮兼容真实 `Song` 对象，并继续写入 `musehub:favorites`。
- Loading、Empty、Error UI 已补齐。
- `/player` 与 `/lyrics` 保持可打开，不接入真实播放和真实歌词。

## 当前限制

- V2 搜索接口当前响应未提供稳定总数时，页面展示当前页结果数量。
- 网易云搜索结果当前未稳定返回时长字段，未知时长展示为 `--:--`。
- 聚合搜索暂不做复杂去重。
- 歌手、专辑、歌单、歌词、MV 分类保留 UI，本阶段不接真实数据。
- 播放按钮仍是 UI/本地状态切换，不请求真实音频。

## 下一阶段建议

- 接入歌曲播放链接接口，明确不可播、付费、无版权等状态。
- 接入歌词接口并给 `/lyrics` 增加真实歌词展示。
- 设计自动换源策略，优先使用当前来源，失败后再尝试其他平台。
- 为搜索结果增加分页或加载更多。
- 在聚合搜索中增加轻量去重和更稳定的排序策略。
