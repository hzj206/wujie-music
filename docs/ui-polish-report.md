# MuseHub 第五阶段 UI 精修报告

## 样式调整

- 新增 `css/polish.css`，集中覆盖圆角、阴影、滚动条、Toast、弹窗和播放器细节。
- 卡片圆角统一向 `24px - 32px` 收拢，阴影降低脏感。
- 主按钮和主播放按钮统一浅金黄渐变。
- input、button、range、Toast、modal 都做了更柔和的奶油风处理。

## 页面优化

- 搜索页：结果 hover 更轻，当前播放项高亮更柔和，失败项不再保留播放样式，并加入“暂无音源”标签样式。
- 播放器页：封面圆角加大，主播放按钮金黄色圆形化，随机/循环/上一首/下一首统一为浅色圆形按钮，播放列表改成胶囊卡片。
- 歌词页：增加奶油色蒙层，弱化背景干扰；歌词滚动条变细；当前歌词粉橘色高亮，字号和字重更突出；底部播放器条更圆润。
- 收藏页：歌单支持网格/列表切换，新建歌单弹窗与删除确认弹窗统一风格。
- 歌单页：新增基础列表页和详情页，空状态延续现有插画资源。

## 滚动条与进度条

- 全站自定义细滚动条。
- 歌词列表、播放器队列、横向歌单和弹窗队列都使用浅色圆润滚动条。
- 进度条高度和拖动点加柔光，拖动区域视觉更自然。

## Toast 与弹窗

- Toast 继续使用轻量实现，样式更圆润、更接近整体奶油暖色。
- 新增通用软弹窗，用于新建歌单、删除确认、清理缓存、歌词设置、更多菜单、播放列表展开。

## 保留边界

- 未接下载、Cookie、扫码登录、用户凭证、本地文件导入。
- 歌词颜色、添加歌曲到歌单、搜索更多分类仍作为后续阶段入口保留。
