# 无界音乐 MuseHub 播放与歌词 API 改造报告

## 修改文件

- `js/api.js`：新增播放链接和歌词接口封装。
- `js/player-service.js`：新增播放业务逻辑、音源解析、质量兜底、轻量自动换源和错误提示。
- `js/lyric-service.js`：新增歌词请求、LRC 解析、翻译歌词合并。
- `js/player.js`：改为全局 `HTMLAudioElement` 播放器，监听音频事件并同步状态。
- `js/lyric.js`：改为真实歌词行工具，支持当前句高亮和自动滚动。
- `js/normalize.js`：补充播放接口返回数据和歌词返回数据标准化。
- `js/storage.js`：新增 `musehub:recent-played` 最近播放。
- `js/search-service.js`：搜索成功后把当前搜索结果同步到播放队列。
- `js/ui.js`：接入真实播放状态、加载态、播放器页歌词、歌词页高亮、收藏页真实最近播放统计。
- `css/components.css`、`css/pages.css`：新增播放 loading 图标和歌词滚动样式。
- `index.html`：加入 `player-service.js`、`lyric-service.js` 并更新资源版本。

## 新增功能

- 搜索结果、收藏页、播放队列播放按钮统一走真实播放链路。
- QQ 音乐接入 `geturl` 播放链接接口，并提供质量降级和整合接口兜底。
- 网易云音乐接入 id 点歌播放接口，并对 `url:null` 做友好提示。
- 全局只创建一个 `audio` 实例，hash 路由切换不打断播放。
- 迷你播放器、底部播放条、播放器详情页、歌词页同步当前歌曲、进度、时长、播放状态。
- 播放成功后写入 `musehub:recent-played`。
- 播放成功后自动请求歌词并解析 LRC。
- 播放器详情页和歌词专注页支持当前歌词高亮。

## 播放测试结果

测试关键词：

- 孤独摇滚
- 星座になれたら
- 晴天
- YOASOBI
- 勾指起誓

接口冒烟结果：

- QQ 音乐：五个关键词首条结果均能获取播放 URL。
- 网易云音乐：五个关键词首条结果均能搜索到歌曲，但本轮接口返回的播放 URL 多为 `null`，页面会提示“当前歌曲暂无可用音源，可以试试其他来源。”

浏览器验证：

- QQ 音乐搜索结果点击播放后，`audio` 进入播放状态。
- 迷你播放器和底部播放条同步进度。
- `/player` 显示真实歌曲信息和歌词。
- `/lyrics` 显示同一首歌并高亮当前歌词。

## 歌词测试结果

- QQ 音乐歌词接口返回 `data.lrc`，已解析并展示。
- 网易云音乐歌词接口返回 `data.lrc` 和 `data.trans`，已解析并保留翻译文本。
- 歌词为空或请求失败时显示“暂无歌词”，不会影响音频播放。

## 当前限制

- 部分网易云歌曲接口返回 `url:null`，属于接口/版权限制，项目只做提示和兜底。
- QQ 音乐返回的可播放 URL 有时是试听音质或试听时长，页面如实展示播放状态，不宣传无损或会员能力。
- 自动换源当前只基于当前播放队列做歌名+歌手完全匹配，不重新发起复杂搜索。
- 播放链接可能过期，收藏歌曲再次播放仍会重新解析音源。

## 下一阶段建议

- 增强自动换源匹配策略，支持轻量相似度和版本选择。
- 增加“加载更多”后的播放队列管理。
- 给不可播放歌曲加更明确的行内状态。
- 支持用户手动选择音质，但仍以可播放优先。
